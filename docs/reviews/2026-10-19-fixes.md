## Integration pass (verify agent)

- **Rotation RPC:**
  - Added `supabase/migrations/20261019070000_set_rotation.sql` and `supabase/tests/database/09_set_rotation.test.sql` (21 checks).
  - `QuotesRepository.setRotation` now calls `set_rotation`. Its signature is unchanged; `SetRotationParams` replaces the internal upsert row.
  - Package request, decoding and local-stack tests were updated.
  - Updated system-design §3 client notes and §4 Data, and `docs/app-store-submission.md` §1. Push the migrations before a build from this tree talks to hosted.
- **New `SocialRepository.markSaved(_:)`:**
  - `LibraryStore.saveShared` now stamps `saved_at` when the quote is already in the library, which closes the "Already in your library is local only" gap.
  - Covered by a request test and a local-stack test.
- **Removed `SheetRoute.safari` and `App/Features/Search/SafariView.swift`:**
  - Updated docs (app-architecture, decision record).
- **Contrast and touch targets:**
  - The `.inlineError` token moved to `App/Design/` and is used in AddEditQuoteView and ShareQuoteSheet.
  - FriendsView "Add a friend" now has its 44 pt target inside the label.
- **UI tests (`UITests/QuotedUITests.swift`)**, new checks:
  - Library "Remove from reminders" then Undo, and Delete then Undo, with reminder positions verified on screen and on the server.
  - "Search the web" opens the Safari app.
  - Inbox swipe-delete then Undo.
  - A deep link while an Add draft is open keeps the draft and opens after Discard.
