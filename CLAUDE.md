# Quoted (iOS + Supabase)
- Native SwiftUI iPhone app, iOS 26+, Swift 6 language mode with strict concurrency. Project generated by XcodeGen from `project.yml`. After editing it, run `xcodegen generate` and commit the regenerated `Quoted.xcodeproj`.
- Code layout: `App/` (app target), `Widgets/` (WidgetKit extension), `Packages/QuotedKit` (SPM: `QuotedCore` = pure models/logic with no Supabase or UIKit; `QuotedKit` = Supabase repositories), `UITests/`, `supabase/` (migrations, tests, functions), `docs/`, `design/`.
- The only third-party dependency is supabase-swift. Add nothing else without asking.
- `docs/system-design.md` is the contract: the data model, RLS, the `body_format` rich-text runs (UTF-16), reminder planning and the module boundaries. Update it when you change a decision.
- The server owns data. Every table has RLS and `with check`. Never trust client values. The client ships only the publishable key. Service-role and secret keys live only in Edge Function env.
- Never run `supabase link`, `db push`, `functions deploy` or anything else against the hosted project (`yyajndbishiyugtbpzmk`). Use the local stack (`supabase start`, `supabase db reset`, `supabase test db`). Hosted deploys are the founder's step (`scripts/deploy-backend.sh`).
- Verify APIs you are unsure of before using them: Xcode SDK `.swiftinterface` files, supabase-swift sources under `.build/checkouts` or DerivedData `SourcePackages/checkouts`, and the Supabase docs (append `.md` to a docs URL). Do not guess API names.
- UI follows the chosen design direction in `design/` (see `docs/decisions/2026-10-18-ui-direction.md`). Draw with native SwiftUI components; no custom imitations of system controls.
- Tests: `swift test` in `Packages/QuotedKit` for `QuotedCore`. `supabase test db` for RLS (pgTAP). UI smoke via `QuotedUITests` against the local stack using the `Debug-Local` configuration.
- A task is done when tests pass, the app builds without warnings in our code, it has been run in the simulator with a screenshot checked, and the work is committed (commit only when the founder asks).
